# Discord 增长与订购转化计划

> **目标：** 让更多人知道并加入 Discord，同时提高 BigTreeSignal 订购率。  
> **原则：** 站外获客 + 站内转化。Discord 是留存和成交场，不是发现场。  
> **约束：** 遵守 Discord ToS 与金融内容合规；不群发陌生人私信、不刷服、不买成员。

相关已有文档：[`PROMOTION_DESIGN.md`](./PROMOTION_DESIGN.md)（服内促销）、[`FEATURE_LIST.md`](./FEATURE_LIST.md)（功能 57–62 获客转化）。

---

## 一、结论先看

现有 Bot **已经能把「进服的人」推向订购**（欢迎 drip、购买意向、YouTube 摘要 CTA、`/invite`、漏斗）。增长卡住，是因为 **进服人数不够**，不是因为服里促销发得不够。

因此本计划分两半，必须同时做：

| 半边 | 要解决的问题 | 现状 |
|------|----------------|------|
| **获客（站外）** | 陌生人如何第一次听到你 | 几乎空白，需要新功能 |
| **转化（站内）** | 进来的人如何试用 / 付费 | 功能已有，先打开并补追踪 |

成功公式：

```
公开内容（可搜索）
    → 带渠道码的落地页 / 邀请链接（可追踪）
    → Discord 加入
    → 前 10 分钟体验 + 24–72h drip
    → 试用
    → 订购
```

只拉人、不转化 → 订购率下降。只转化、不拉人 → 订购人数到顶。两边都要看。

## 二、你 vs AI vs 新功能（总表）

| 层级 | 你（频道主）做什么 | AI / 自动化做什么 | 需要新开的功能 |
|------|-------------------|-------------------|----------------|
| **定位与合规** | 定对外口号、免责声明、哪些内容可公开 | 按模板给每条公开稿加免责声明 | 公开内容消毒器 |
| **追踪** | 为 YouTube / X / 小红书 / 合作方各建一个邀请码 | 记录加入来源、写入漏斗 | 渠道邀请码 + 来源漏斗 |
| **内容** | 每天审核 5–10 分钟；亲自发 1–2 个主平台 | 从当日精华生成 4 种站外稿 | 内容工厂 + Owner 审核队列 |
| **分发** | 谈合作、拍口播、回复评论 | 审核通过后导出文案；后期可接平台 API | 分发导出 / 可选自动发帖 |
| **裂变** | 设奖励身份组、在频道置顶「分享有奖」 | `/invite` 归因、月榜、一键公开发版 | 邀请月榜 + `/share` |
| **转化** | 配好试用 URL、VIP 身份组、欢迎文案 | 欢迎 drip、意向识别、CTA 按钮 | 补「加入后 7 日是否发言」 |
| **决策** | 每周看漏斗，加码有效渠道、关掉无效渠道 | `/funnel` 按来源拆解 | 增长看板 |

## 三、现状：已有能力 vs 缺口

### 已有（服内转化，优先打开）

| 能力 | 模块 | 作用 |
|------|------|------|
| 购买意向 → 产品 CTA + 通知你 | `bot/acquisition.py` | 有人问价格/试用时直接成交 |
| 新人 24–72h drip | `bot/welcome_flow.py` | 欢迎 → 价值证明 → CTA → 提醒 |
| YouTube 新视频 → 摘要 + CTA | `bot/youtube_monitor.py` | 教育内容顺带获客 |
| `/invite` 专属邀请 + 奖励身份组 | `bot/acquisition_cog.py` | 老带新 |
| `/funnel` 漏斗 | `bot/acquisition.py` | 加入 / 欢迎 / 意向 / CTA |
| 日/周总结 | `bot/daily_summary.py`, `bot/weekly_summary.py` | **最好的对外内容原料** |
| 用户见证审核 | `bot/testimonials.py` | 社会证明 |
| 自愿通知私信 | `bot/role_dm.py` | 只给点过「领取通知」的人发 |

注意：`WELCOME_FLOW_ENABLED` 默认是 `false`。转化漏斗若没打开，拉再多人也会流失。

### 缺口（站外获客，本计划要建）

1. 没有「可公开发版」：日总结锁在 Discord 里，Google / 小红书搜不到。
2. 邀请链接没有**渠道维度**（只有成员个人码，没有 `youtube` / `xhs`）。
3. 没有落地页：陌生人点 `discord.gg` 不知道里面有什么。
4. 没有对外审核队列：金融内容不能全自动发到公网。
5. 漏斗没有「来源 → 加入 → 发言 → 试用 → 付费」全链路。
6. 5000 人没有变成稳定分发网（`/invite` 有了，缺月榜和一键转发包）。

## 四、衡量什么（否则会空转）

只看这 6 个数字，每周用 `/funnel` 和增长看板对照：

| 指标 | 含义 | 健康方向 |
|------|------|----------|
| **渠道加入数** | 每个邀请码每周新成员 | 找到 1–2 个可加倍的渠道 |
| **7 日激活率** | 加入后 7 天内发过言或用过 `/ask` | 目标 ≥ 20%；低了是欢迎流程问题 |
| **意向数** | 问价格/试用的人数 | 内容是否吸引「要买信号的人」 |
| **试用点击** | CTA / 试用按钮 | 产品页和试用入口是否通 |
| **付费数** | 实际订购（需你或支付平台回写） | 北极星 |
| **老带新占比** | `invite_joins` / `joins` | 健康社群会慢慢升高 |

没有「来源」的加入，一律记为 `unknown`，逼自己把链接拆开。

## 五、分阶段计划

### Phase 0 — 打开已有转化（约 1 周，几乎不写代码）

**目的：** 新进来的人不要白来。订购率先靠转化，再靠流量。

**你做：**

1. `.env` 打开并填真实链接（不要占位域名）：
   - `WELCOME_FLOW_ENABLED=true`
   - `SIGNAL_PRODUCT_URL`、`FREE_TRIAL_URL`、`FREE_TRIAL_ENABLED=true`
   - `INTENT_CONVERT_ENABLED=true`、`INTENT_LEAD_ROLE_ID`（咨询中身份组）
   - `INVITE_TRACKING_ENABLED=true`、`INVITE_REWARD_ROLE_ID`、阈值
   - `YOUTUBE_MONITOR_ENABLED=true` 及频道 ID
   - `DAILY_SUMMARY_ENABLED=true`
   - `PROMO_NOTIFY_ROLE_IDS` + 在公告频道 `/promo_notify_panel`
2. Discord 后台为每个渠道建**永久邀请**（或等 Phase 1 的渠道码功能）：YouTube、X、小红书、合作、口碑。
3. 服务器简介、标签、Vanity URL 写上「美股分析 / US stocks」。
4. 公开欢迎频道：30 秒看懂规则、今日看点、如何 `/ask`、如何 `/signal`。
5. 确认 Bot 有：创建/查看邀请、Server Members Intent、管理目标身份组。

**AI / 自动化做：** 已有模块自动跑欢迎 drip、意向 CTA、YouTube 摘要按钮、邀请归因。

**新功能：** 无。先验证漏斗数字在动。

**完成标准：** `/funnel` 能看到 joins、welcome_dm_ok、intent_hits；试用链接可点开。

---

### Phase 1 — 内容工厂（约 2–3 周，核心新功能）

**目的：** 把每天已经在频道里产生的分析，变成可搜索、可转发的公开内容。这是获客的主引擎。

#### 你做

- 定 3 条对外红线：不公开他人持仓/盈亏、不公开未审核的买卖点、每条带免责声明。
- 每天固定 5–10 分钟：在审核队列点「过 / 改 / 弃」。
- 亲自运营 **1 个主平台**（建议 YouTube Shorts 或 X），评论区回复并放邀请链接。
- 不要追求 6 个平台都日更；1 个平台做透，胜过 6 个平台发完没人看。

#### AI / 自动化做

每天在日总结生成之后（复用 `daily_summary.py` 的原料）：

1. 抽取 1 个高互动主题（可结合当日消息热度）。
2. 生成 **公开发版**（去成员名、去私密数字、加免责声明）。
3. 同时产出 4 种稿：
   - 60–90 秒口播稿（短视频）
   - X / Twitter 线程（8–12 条）
   - 小红书图文（标题 + 正文 + 标签）
   - SEO 短文标题 + 正文（给落地页 / 博客）
4. 每条稿尾部带**该日默认渠道邀请链接**。
5. 草稿进 Owner 审核队列（复用 `review.py` 的 Approve / Edit / Reject 模式），**默认不自动公开发布**。

#### 要开的新功能

| 功能 | 建议文件 | 说明 |
|------|----------|------|
| **公开内容消毒器** | `bot/growth_sanitize.py` | 去掉 @提及、用户 ID、私密盈亏、内部频道名；强制免责声明 |
| **内容工厂** | `bot/growth_factory.py` | 输入日总结 + RAG 风格 → 4 种站外稿 JSON |
| **增长审核队列** | `bot/growth_review.py` | DM 你审核；通过后写入 `data/growth_pack.json` |
| **`/growth_pack`** | `bot/commands.py` | Owner 立即生成今日包，或查看待审列表 |
| **渠道邀请码** | 扩展 `bot/acquisition.py` | 预置 `youtube` / `xhs` / `twitter` / `partner` / `organic`；加入时记来源 |
| **漏斗来源字段** | `data/funnel.json` | `joins_by_source`；`/funnel` 按渠道展示 |

**完成标准：** 连续 5 个交易日，你审核后都有一份可复制的四件套；至少 1 个站外平台开始日更或周更。

---

### Phase 2 — 落地页 + 分发（约 2 周）

**目的：** 陌生人点进来先理解价值，再进 Discord；邀请链接可追踪。

#### 你做

- 准备 3 张匿名化精华截图、1 段「这是谁」介绍、免责声明终稿。
- 域名或沿用现有 `web-client` 子路径，例如 `/join`。
- 每个平台的简介/片尾只放**该平台专属链接**（落地页 `?src=youtube` 或对应 discord 邀请）。
- 开始谈合作：每周 1 个美股博主 / newsletter，带成品样例而不是口头介绍。

#### AI / 自动化做

- 落地页「本周精华」自动取最近一次已审核的 growth pack。
- 审核通过的稿一键导出：`.txt` / `.md` / 字幕 SRT，方便你贴到各平台。
- YouTube 视频描述模板：自动生成时间戳草稿 + 邀请 CTA（你上传时粘贴）。

#### 要开的新功能

| 功能 | 建议位置 | 说明 |
|------|----------|------|
| **公开加入页** | `web-client` 新路由或独立静页 | 定位、3 条精华、见证、大按钮「加入 Discord」、来源参数 |
| **公开 API：本周精华** | `bot/api/routes_public.py` | 只返回已审核、已消毒内容 |
| **`/share`** | `bot/commands.py` | 对某条消息或今日总结生成「可公开发版」+ 该成员的 `/invite` 链接 |
| **导出命令** | `/growth_export` | 把已通过的稿打成文件发到你的 DM |

**完成标准：** 从 YouTube 点进来的人，漏斗里能看到 `youtube` 来源；落地页可以独立打开，不强制先装 Discord。

---

### Phase 3 — 把 5000 人变成分发网（约 2 周）

**目的：** 获客从「你一个人发」变成「成员愿意转发」。

#### 你做

- 定奖励：有效邀请（加入后 7 日有发言）满 N 人给角色 / 试用，而不是发钱。
- 置顶说明：如何 `/invite`、如何 `/share`、什么能发什么不能发。
- 每月公布邀请榜（可公开频道，形成荣誉而不是骚扰）。

#### AI / 自动化做

- 维持现有邀请归因；达到阈值自动给身份组（已有）。
- 月榜：有效邀请排序。
- 成员点 `/share` 得到去标识文案 + 自己的邀请码，降低转发成本。

#### 要开的新功能

| 功能 | 说明 |
|------|------|
| **有效邀请** | 加入后 7 日激活才计入奖励（防刷号） |
| **`/invite_leaderboard`** | 月榜，仅统计有效邀请 |
| **分享卡片** | 可选：把公开发版做成一张图（标题 + 金句 + 二维码），方便小红书 |

**完成标准：** `invite_joins` 占每周 joins 的比例开始上升；出现稳定的前 10 名邀请者。

---

### Phase 4 — 放大有效渠道（按需，不要提前做）

仅当 Phase 1–3 已经能指出「哪个渠道带来会发言、会问价格的人」之后再做：

| 动作 | 你做 | AI 做 | 新功能 |
|------|------|-------|--------|
| 平台 API 直发 | 授权 X / YouTube 账号 | 审核通过后定时发 | `bot/growth_publish.py`（仍禁止未审即发） |
| 搜索广告 / 信息流 | 投落地页，不投裸邀请 | 生成 5 组广告文案 A/B | 落地页事件回传 |
| Discord Discovery | 打开并填完整服务器资料 | — | 无 |
| 付费回写 | 在支付成功页或你手动 `/mark_paid` | 漏斗记 `paid` | 订购事件 API |

没有来源数据就投广告，等于看不见回报。

## 六、新功能清单（按实现顺序）

建议作为后续独立开发任务，不要和 Bot 核心 RAG 缠在一起。

### 必须有（P0）

1. **渠道邀请码与来源归因** — 扩展 `acquisition.py` / `acquisition_cog.py`
2. **7 日激活追踪** — 加入时记下 `joined_at`，发言或 `/ask` 时记 `activated_at`
3. **内容工厂 + 消毒器 + 审核队列** — `growth_factory` / `growth_sanitize` / `growth_review`
4. **`/growth_pack`、`/funnel` 带来源** — Owner 命令

### 强烈建议（P1）

5. **公开加入页 + 本周精华 API**
6. **`/share` + `/growth_export`**
7. **有效邀请 + `/invite_leaderboard`**
8. **漏斗补 `trial_clicks` / `paid`**（按钮点击与手动/支付回写）

### 可以后做（P2）

9. 分享卡片出图  
10. X / YouTube 审核后自动发布  
11. 广告文案生成与落地页像素  

### 明确不做

- 批量加好友 / 私信陌生人  
- 进别人服务器发邀请  
- 买成员、假号互拉  
- 未审核的交易建议自动发到公网  
- 用非自愿身份组群发私信（现有 `role_dm.py` 已禁止）

## 七、建议的模块结构（实现时）

```
bot/
  growth_sanitize.py    ← 公开发版规则
  growth_factory.py     ← 4 种稿生成（调 LLM + 风格档案）
  growth_review.py      ← Owner 审核，复用 Button 模式
  growth_cog.py         ← 日更任务 + slash commands

data/
  growth_pack.json      ← 每日草稿 / 已通过稿
  growth_sources.json   ← 渠道码定义
  activations.json      ← 加入与 7 日激活
```

日更触发点：挂在现有 `DailySummaryCog` 成功发帖之后，避免再扫一遍频道。

公开稿必须走风格档案（`data/style_profile.txt`），口吻与频道一致，但 **事实以当日 Owner 消息为准**，禁止模型编造价位和盈亏。

## 九、风险与合规

- **金融内容：** 公开稿统一页脚：「内容仅为教育交流，不构成投资建议」。买卖点、目标价默认不进公开发版，除非你在审核时手动加回。
- **隐私：** 消毒器删除成员名、账号、截图中的 UID；见证需已有 testimonials 审核通过才可上落地页。
- **Discord：** 邀请追踪需要 Members Intent；群发仅限自愿通知身份组。
- **品牌：** 宁可不发，不要让模型在公网「预测明天必涨」。审核队列是功能，不是障碍。

## 十、和订购率的关系（避免只追人数）

```
站外内容质量 ↑
  → 来的人更像「要看美股/要信号」的人
  → 7 日激活率、意向数、试用点击 ↑
  → 订购率 ↑

站外内容变成「求加群」
  → 来的人是凑数的
  → 激活率 ↓，你觉得订购率更差
```

因此内容工厂的选题必须是 **可搜索的美股问题**，CTA 只放在结尾。欢迎词和 `/signal` 负责成交，公开内容负责信任。

## 十一、建议的下一步

1. 你先完成 **Phase 0**（打开欢迎 drip、真实产品/试用 URL、邀请奖励身份组）。  
2. 确认要做 Phase 1 后，按本文第六节 P0 实现：渠道码、激活追踪、内容工厂、审核队列。  
3. 主平台选定一个（YouTube Shorts 或 X），再开落地页。

若开始写代码，优先顺序是：**渠道邀请码 → 内容工厂+审核 → `/share` → 落地页**。
