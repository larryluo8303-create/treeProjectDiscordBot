# DM 触达方案（全员推广消息触达）

> 背景：服务器公告（含 @everyone）实际只能触达几十人，大部分成员不看群公告。
> 本方案是"让一条推广消息触达每一个 Discord 成员"的标准打法，可复用于任何全员推广
> （免费试用、促销、活动、新功能上线等）。2026-10-17 由 larry 确认采用。

## 四层触达（按触达率排序）

### 第 1 层：bot 分批 DM（主力，触达率最高）
- 给全员逐个发推广私信，文案带用户名、一次说清价值 + 领取方式。
- **必须节流**：每条间隔 8–12 秒随机，每天上限 400 条（5000 人约 10 天发完）。
  Discord 反垃圾机制会对短时间大量 DM 限流，严重会封 bot。
- 跳过：机器人、已有付费组（懒人🌴/懒人etf🌲）成员、已退订（opt-out）名单。
- DM 发不出去（对方关闭"允许来自服务器成员的私信"，403）→ 记入名单，走第 3 层补。
- 状态文件记录 sent / skipped / failed / dm_closed / opted_out，支持断点续跑、幂等。
- 脚本：`bot-ops/dm_broadcast.py`（独立运行，不依赖线上 bot；支持 --dry-run）。

### 第 2 层：行为触发 DM（打开率最高）
- 在用户"活跃时刻"触达：在服务器发第一条消息 / 新加入 / 首次 reaction 时，
  若符合推广资格且未收到过推广 DM，自动 DM 一次。
- 人正在看手机时收到，打开率是群发的数倍。
- 实现：bot listener（`bot/listener.py` 或独立 cog），与第 1 层共用文案模板与 opt-out 名单。

### 第 3 层：群公告备份（覆盖 DM 发不出去的人）
- @everyone + 置顶 + 欢迎频道常驻，专门捞第 1 层触达失败的人。

### 第 4 层：推广大使人传人（补盲区）
- DM 不看、私信关闭的人，由推广大使去拉。见《推广大使计划》。

## 合规红线（必守）
- 每条推广 DM 必须带退订方式（"回复 STOP 不再接收推广"），用户回复 STOP/退订后永久不再打扰。
- 同一推广主题，同一用户最多收到 1 次群发 DM + 1 次行为触发 DM，避免骚扰。
- 节流参数只可调小不可调大；如收到 Discord 警告，立即暂停群发。

## 文案模板（每次推广替换内容，结构不变）
```
{用户名} 你好！我是 bigTreeSignal 的助手 🤖

{一句话价值：如"免费领 1 个月完整美股信号"}
{领取方式：如"在群里输入 !试用 即可领取"}
{截止时间 / 名额限制，制造紧迫感}

不想再收到推广？回复 STOP，我不会再打扰你。
```

## 复用清单（下次推广直接照做）
1. 定文案 → 用户审稿
2. `dm_broadcast.py --dry-run` 验证名单与文案
3. 小批量试发 50 人，观察送达率与投诉
4. 全量分批发送（每天 400）
5. dm_closed 名单 → 群公告补
6. 数据复盘：送达率、领取率、转化率 → 记入下次优化
