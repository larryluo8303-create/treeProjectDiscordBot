# BigTree 社群盘活与订购转化计划书

> 适用：约 5000 人、运营 5 年+ 的 Discord 社群  
> 成交产品：订阅介绍频道（BigTreeSignal）  
> 介绍页：[订阅介绍频道](https://discordapp.com/channels/895349295975370802/923313988996051005)  
> 成交方式：看完介绍后，**私信频道主**开通  
> 配套功能清单：见 [`FEATURE_LIST.md`](./FEATURE_LIST.md) 第 57–62 条；推广命令见 [`PROMOTION_GUIDE.md`](./PROMOTION_GUIDE.md)

本文是给频道主的操作手册：你做什么、Bot/AI 做什么、按哪一周做、文案怎么发。不群发未同意成员的促销私信。

## 一、目标与转化路径

**目标（90 天）**

1. 叫醒还开着 Discord 通知、偶尔会进服的老成员  
2. 让他们先看到订阅介绍频道  
3. 有意向的人私信你开通，提高订购率  

**唯一成交路径（不要改）**

```text
被内容/公告叫醒
  → 点进订阅介绍频道（产品页）
  → 私信频道主开通
  → 你报价、收款、加上 VIP 身份组
```

- **介绍频道** = 产品页，负责讲清楚买什么  
- **私信你** = 收银台，负责成交  
- **Bot** = 导购：把人叫醒、把人带到介绍页、把询价的人通知给你  

5000 人不能靠群发私信叫醒。很多人关了「允许服务器成员私信」，群发送达率差，还容易被投诉。唤醒用**公告频道**；订购用**介绍页 + 私信你**。

## 三、你本周必须完成的清单（第 0 周）

全部是 Discord 后台操作，不改代码也能先做完第 1–8 步。

### 1. 建公告频道

1. 服务器设置 → 启用社区（若尚未开启）  
2. 创建类型为「公告」的频道，例如 `#公告`  
3. `@everyone`：只给「查看频道」，不要给「发送消息」  
4. 给你自己和 Bot：发送消息、提及 everyone、管理消息（方便置顶）

### 2. 建三个身份组

| 身份组建议名 | 权限 | 写入 `.env` |
| --- | --- | --- |
| 活动通知 | 无管理权限 | `PROMO_NOTIFY_ROLE_IDS=` |
| 咨询中 | 无管理权限 | `INTENT_LEAD_ROLE_ID=` |
| VIP（若还没有） | 按你现有会员权限 | `VIP_ROLE_IDS=` |

然后：

- 把 **Bot 身份组拖到这三个的上面**  
- Bot 角色勾选 **管理身份组**  
- 填好 `.env` 后**重启 Bot**

复制身份组 ID：服务器设置 → 高级 → 开启开发者模式 → 右键身份组 → 复制 ID。

### 3. 确认介绍频道谁能看

[订阅介绍频道](https://discordapp.com/channels/895349295975370802/923313988996051005) 建议：

- 所有人**可以查看**（否则「了解产品」按钮点进去没权限）  
- 普通成员**不能在里面灌水**（只你和 Bot 能发），保持它像产品页  

若该频道目前只有 VIP 能进，导购按钮会失效。至少让「咨询中」和所有人只读可见；成交后的独家内容可另开 VIP 频道。

### 4. 置顶订阅面板

在公告频道输入：

```text
/promo_notify_panel
```

把 Bot 发的那条**置顶**。

### 5. 发第一条回归公告（可复制）

在公告频道发下面这段，需要叫醒全服时加上 `@everyone`（建议整季只用 1–2 次）：

```text
@everyone

社群开了 5 年，很多朋友可能很久没进来了。

最近我们把每日要点、视频摘要和问答助手都自动化了：
• 想看产品介绍 → 订阅介绍频道
• 想收活动私信 → 点本频道置顶的「领取通知」（自愿，随时可取消）
• 想开通 → 看完介绍后私信我

介绍频道：https://discordapp.com/channels/895349295975370802/923313988996051005
```

把「订阅介绍频道」改成 Discord 里的 `#频道名` 提及也可以。

### 6. 准备你自己的三句成交话术（私信里复制即用）

**有人来问价格时：**

```text
你好，介绍在这个频道：
https://discordapp.com/channels/895349295975370802/923313988996051005

看完有问题直接问我。开通我来帮你处理。
```

**对方说想买时：**（改成你的真实价格与付款方式）

```text
可以。价格是 ____，付款方式 ____。
你付好把截图发我，我给你开 VIP。
```

**对方只是回来看看时：**

```text
先看介绍频道就行。想收活动通知去公告频道点「领取通知」。
准备开通了私信我。
```

没有这三句，Bot 把人送到你私信后你会接不住。

## 四、每天 / 每周你做什么

**每天（10–20 分钟）**

1. 看 Discord 里「咨询中」身份组：有新人就在 24 小时内私信（可先发上面第一段话术）  
2. 看 `/funnel days:7`：加入、欢迎私信成功/被拒、`/signal`、购买意向  
3. 介绍频道、公告频道有没有人问「怎么买」——Bot 应已自动回，你只要跟私信  

**每周（一次）**

1. 检查日总结、YouTube 摘要、FAQ 是否在正常时间发出  
2. 对已有运营分组：在对应频道 `@那一组` 发一条本周值得看的内容 + 介绍频道链接（不是私信）  
3. 若「活动通知」已有人领取：可用 `/dm_role` 发一条回归提醒，结尾写「介绍频道 + 开通请私信我」。先看人数再确认。单次默认最多 200 人  

**不要做**

- 按「多久没发言」给 5000 人群发私信  
- 把你手动打的兴趣标签拿来群发私信  
- 每天 `@everyone` 或每天刷促销

## 六、为达成目标要新开的功能（开发优先级）

做完第 0 周清单后，按这个顺序改 Bot。没有这些，介绍频道已经能点，但「送到你私信」这一步偏弱。

### P0 — 导购按钮对齐成交路径（先做）

所有产品卡（`/signal`、询价自动回复、欢迎私信、YouTube 摘要按钮）统一成两步：

1. **了解产品** → 打开 [订阅介绍频道](https://discordapp.com/channels/895349295975370802/923313988996051005)（已有 `SIGNAL_PRODUCT_URL`）  
2. **私信频道主开通** → 提示用户私信你，并给你发线索卡（谁、哪个频道、点了按钮还是问了价格）  

另加公开命令 `/subscribe`：不会问「多少钱」的人也能点。  
漏斗增加：介绍页点击可继续用现有 `/signal`；新增订阅按钮点击次数。

配置建议：`SUBSCRIBE_VIA_OWNER_DM=true`。介绍频道 URL 保持不变。

### P1 — 沉睡成员「露头就接住」

90 天没在目标频道发言的人，一旦说话：

- 回一句欢迎回来  
- 带上「了解产品 / 私信频道主开通 / 领取通知」  

每人很长周期只触发一次。这是叫醒 5 年老成员里，比群发 DM 更有效的自动化。

### P2 — 频道主线索列表

- `/leads`：最近「咨询中」是谁、何时、从哪来  
- `/lead_done @用户`：去掉咨询中、记一笔成交（你已加 VIP 后点）  

否则询价一多，只靠脑子记会漏单。

### P3 — 自愿名单上的回归私信

代码已有（[`FEATURE_LIST.md`](./FEATURE_LIST.md) 第 62 条）。第 0 周配好「活动通知」并有人领取后即可用，不必等 P0 做完。

**不做：** 自动代替你报价；对未领取通知的人群发促销私信。

## 八、怎么判断有没有盘活、有没有提高订购

不要看「发了多少私信」。每周记这几项（`/funnel days:7` + 你自己数 VIP）：

| 指标 | 含义 |
| --- | --- |
| 7 日在频道发言的人数 | 有没有被叫醒 |
| 领取「活动通知」的人数 | 自愿名单有没有变大 |
| `/signal` 次数、介绍频道活跃 | 有没有人在看产品页 |
| 购买意向次数 + 「咨询中」人数 | 有没有人走到收银台门口 |
| 你本周新加的 VIP 人数 | 真正订购率 |

若「咨询中」很多但 VIP 不涨：瓶颈在你私信回复速度或介绍频道讲不清楚，不是 Bot 没群发。  
若发言和 `/signal` 都不涨：先加强第 0 周公告和每日内容，不要加群发私信。
